# Ace Tennis — мобильные приложения

Приложение для iOS (и при желании Android) — это «оболочка» вокруг сайта https://ace-tennis.uz
на Capacitor: всё, что меняется на сайте, сразу появляется и в приложении, новая версия в магазине нужна
только при изменении самой оболочки (иконка, разрешения, push-уведомления).

* `capacitor.config.json` — id приложения `uz.acetennis.app`, адрес сайта, цвета.
* `assets/` — иконка 1024×1024 и заставка 2732×2732 (из них @capacitor/assets собирает все размеры).
* `www/index.html` — экран «нет интернета».
* `scripts/ios-plist.mjs` — тексты разрешений (геолокация, фото, камера) для проверки Apple.
* `.github/workflows/ios.yml` (в корне репозитория) — сборка на Mac-сервере GitHub. Проверочная сборка идёт
  без подписи; для выкладки в App Store нужны сертификаты Apple — их добавляет владелец аккаунта
  в Settings → Secrets репозитория (никому не пересылать).
